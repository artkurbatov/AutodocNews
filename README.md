# AutodocNews

Приложение отображает новостную ленту от Autodoc.ru.

## Технологии

- **Язык**: Swift
- **UI**: UIKit, UICollectionView, Diffable Data Source, Compositional Layout
- **Архитектура**: MVVM, Combine
- **Сеть**: Все запросы async/await
- **Минимальная версия**: iOS 16.0

## Основные возможности

- Постраничная загрузка новостей (пагинация)
- Кэширование изображений
- Тематический лоадер в виде колеса автомобиля
- Адаптивный дизайн (iPhone + iPad)
- Поддержка поворота экрана
- Поддержка темной темы
- Открытие полной новости в WebView
